Pour effectuer des requêtes à l'API Weblate, il est nécessaire d'avoir une clé d'API.

Pour cela: 
1. Dans l'interface Weblate, cliquez sur `Projects` dans le menu du haut et sélectionnez votre projet
![6](https://github.com/thetribeio/etandem/assets/14289151/c875831d-9a51-46dd-aba6-27f99b3cd326)
2. Cliquez sur `Manage` puis `API access`
![7](https://github.com/thetribeio/etandem/assets/14289151/f102d52e-23d4-4643-a813-49c3cc0420fe)
3. Renseignez un nom pour la clé d'API, si vous le souhaitez une date d'expiration, et cliquez sur créer. Un message en haut de la page vous permettra de copier la clé d'API générée.
![8](https://github.com/thetribeio/etandem/assets/14289151/5e774b31-346a-451e-92cb-f93861668527)
