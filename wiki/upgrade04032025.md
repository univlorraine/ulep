# Guide de mise à jour des déploiements

## 1. Weblate

**Version actuelle :** 4.18  
**Version cible :** 5.10.2.0

### Étapes de mise à jour
1. Sauvegarde de la base de données
2. Upgrade vers 5.0.2.2
   ```yaml
   weblate:
     image:
       repository: "weblate/weblate"
       tag: "5.0.2.2"
   ```
3. Tests et validation
4. Upgrade vers 5.10.2.0
   ```yaml
   weblate:
     image:
       repository: "weblate/weblate"
       tag: "5.10.2.0"
   ```


## Notes importantes

- **Sauvegardes** : Effectuer des sauvegardes complètes avant chaque mise à jour
- **Tests** : Valider chaque étape dans un environnement de test
- **Rollback** : Prévoir une procédure de retour arrière en cas de problème
- **Monitoring** : Surveiller les performances après chaque mise à jour
- **Documentation** : Documenter les changements et problèmes rencontrés
