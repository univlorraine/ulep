> Conformément à l’article 47 de la loi n° 2005-102 du 11 février 2005 pour l’égalité des droits et des chances, la participation et la citoyenneté des personnes handicapées, il est traité dans cette partie de la mise en conformité de l'application au regard des recommandations du WCAG (Web Content Accessibility Guidelines) ainsi que du WAI-ARIA (Accessible Rich Internet Applications) repris dans le RGAA - Version 4.1.2 (Référentiel général d’amélioration de l’accessibilité), pour une meilleure accessibilité du site pour les personnes en situation de handicap.

L’accessibilité numérique consiste à rendre les contenus et services numériques compréhensibles et utilisables par les personnes en situation de handicap au sens de l'article L. 114 du code de l’action sociale et des familles.

Parmi l'ensemble des critères mis en oeuvre par le référentiel, seuls les critères se rapportant à des fonctionnalités de l'application ont été retenus.

Ainsi, il est développé comme suit les différents critères sélectionnés :

# Images
* Chaque image porteuse d’information a une alternative textuelle pertinente et une description détaillée
* Chaque image de décoration est correctement ignorée par les technologies d’assistance

# Liens
* Chaque lien possède un intitulé explicite
* Dans chaque page web, les contenus additionnels apparaissent au survol, à la prise de focus ou à l’activation d’un composant d’interface  et sont, si nécessaire, atteignables au clavier

# Couleurs
* Pour chaque page, l’information n'est pas uniquement définie par la couleur
* Pour chaque page, le contraste est suffisamment élevé :
    1. Entre la couleur du texte et la couleur de son arrière-plan
    2. Entre les couleurs utilisées dans les images d'illustrations ou les éléments graphiques porteurs d’informations

# Tableaux
* Chaque tableau de données complexe a un résumé pertinent
* Pour chaque tableau de mise en forme, le contenu linéarisé reste compréhensible
* Pour chaque tableau de données ayant un titre, le titre est correctement associé au tableau de données et est pertinent
* Pour chaque tableau de données, chaque en-tête de colonne et chaque en-tête de ligne sont correctement déclarés
* Pour chaque tableau de données, la technique appropriée permettant d’associer chaque cellule avec ses en-têtes est utilisée (hors cas particuliers)
* Chaque tableau de mise en forme n'utilise pas d’éléments propres aux tableaux de données

# Formulaires 
* Chaque champ de formulaire a une étiquette et a un contenu pertinent (input label)
* Dans chaque formulaire, chaque étiquette de champ et son champ associé sont accolés
* Dans chaque formulaire, les champs de même nature sont regroupés, si nécessaire

# Navigation
* Dans chaque ensemble de pages, le menu et les barres de navigation sont toujours à la même place (sauf les boîtes de dialogues)
* Dans chaque page web, l’ordre de tabulation est cohérent
* Dans chaque page web, la navigation ne contient pas de piège au clavier

# Présentation de l’information 
* Le texte reste lisible lorsque la taille des caractères est augmentée jusqu’à 200 %
* Chaque lien dont la nature n’est pas évidente est visible par rapport au texte environnant
* Les déclarations CSS de couleurs de fond d’élément et de police sont correctement utilisées (color, background-color, background)
* Chaque lien dont la nature n’est pas évidente est visible par rapport au texte environnant
* Pour chaque élément recevant le focus, la prise de focus est visible
* Chaque contenu caché a vocation a être ignoré par les technologies d’assistance
* L’information n'est pas donnée uniquement par la forme, taille ou position
* Les contenus peuvent-être présentés sans perte d’information ou de fonctionnalité et sans avoir recours soit à un défilement vertical pour une fenêtre ayant une hauteur de 256 px, soit à un défilement horizontal pour une fenêtre ayant une largeur de 320 px

# Structuration de l'information
* Dans chaque page web, l’information est structurée par l’utilisation appropriée de titres
* Dans chaque page web, la structure du document est cohérente (hors cas particuliers)
* Dans chaque page web, chaque liste est correctement structurée

# Consultation
* Dans chaque page web, l’ouverture d’une nouvelle fenêtre ne peut-être déclenchée sans action de l’utilisateur
* Dans chaque page web, chaque document bureautique en téléchargement possède, si nécessaire, une version accessible
* Pour chaque document bureautique ayant une version accessible, cette version offre la même information
* Dans chaque page web, chaque contenu cryptique (émoticône, syntaxe cryptique) a une alternative pertinente
* Aucune page web n'a de contenu en mouvement, clignotant, effectuant un changement brusque de luminosité ou un effet de flash
* Dans chaque page web, le contenu proposé est consultable quelle que soit l’orientation de l’écran (portrait ou paysage)
* Dans chaque page web, les fonctionnalités sont utilisables ou disponibles au moyen d’un geste simple
* Dans chaque page web, les actions déclenchées au moyen d’un dispositif de pointage sur un point unique de l’écran peuvent faire l’objet d’une annulation

# Éléments obligatoires
* Chaque page web est définie par un type de document (doctype)
* Dans chaque page web, le code source généré est valide selon le type de document spécifié
* Dans chaque page web, la langue par défaut est présente et pertinente
* Chaque page web a un titre de page
* Dans chaque page web, chaque changement de langue est indiqué dans le code source
* Dans chaque page web, le code de langue de chaque changement de langue est valide et pertinent
* Dans chaque page web, les balises ne sont pas utilisées uniquement à des fins de présentation.

# Scripts
* Chaque script est, si nécessaire, compatible avec les technologies d’assistance
* Pour chaque script ayant une alternative, cette alternative est pertinente
* Chaque script est contrôlable par le clavier et par tout dispositif de pointage
* Pour chaque script qui initie un changement de contexte, l’utilisateur en a le contrôle
* Dans chaque page web, les messages de statut sont correctement restitués par les technologies d’assistance
